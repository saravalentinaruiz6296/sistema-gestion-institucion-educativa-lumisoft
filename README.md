# Sistema de Gestión Institución Educativa Lumisoft

Repositorio del proyecto **Sistema de Gestión Institución Educativa**, desarrollado como una aplicación web para una institución educativa ficticia llamada **Academia Atenea**.

Este proyecto tiene como propósito presentar la información institucional de manera organizada e intuitiva, incluyendo la oferta académica, servicios, noticias y canales de contacto para la comunidad educativa.

Además, este repositorio se utiliza para aplicar buenas prácticas de **control de versiones y trabajo colaborativo** mediante Git y GitHub.

---

# Objetivo del proyecto

Desarrollar una aplicación web institucional que permita presentar la información más importante de la Academia Atenea de forma clara, organizada y accesible para estudiantes, padres de familia y visitantes.

---

# Funcionalidades

- Página de inicio institucional.
- Información de la institución.
- Historia, misión, visión y perfil institucional.
- Programas académicos.
- Servicios institucionales.
- Noticias y eventos.
- Página de contacto.
- Navegación mediante menú desplegable.
- Diseño adaptable y organizado.

---

# Convención de commits

Los commits siguen la especificación **Conventional Commits**.

Ejemplos:

```bash
feat: agregar sección de noticias
fix: corregir enlace del menú principal
style: mejorar estilos del footer
docs: actualizar README del proyecto
refactor: reorganizar estructura del código
```
